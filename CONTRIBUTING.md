# Contributing

Thanks for wanting to help Startide. Its source isn't published, so code contributions aren't
possible here, but these help a lot:

- **Bug reports.** [Open an issue](https://github.com/noerdk/startide/issues/new/choose) with the
  bug template. The two files in `App/Startide/logs/` are the single most useful thing to attach.
- **Device reports.** Tried it on MinUI, an original Miyoo Mini, or another firmware? Tell us
  what worked and what didn't, with `logs/current.txt`.
- **Ideas.** Use the feature-request template. Startide is meant to stay calm and simple, so
  the best ideas make it more beautiful to sit with rather than add buttons.
- **Music.** Made something with Startide? Share it in an issue tagged *showcase*: it helps
  others hear what it can do.

Please be kind: see the [code of conduct](CODE_OF_CONDUCT.md).
